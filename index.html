正式版怎麼接 Google 日曆

  1. 公司 Google Workspace 建一個「工程部保養排程」共用日曆，每位工程師、主管都看得到。
  2. 主管派工時，App 用 Google Calendar API 直接寫入共用日曆，事件內容帶客戶、設備序號。
  3. App 讀取共用日曆，比對序號：同一台設備被兩個人排、或同一家客戶同一天兩個人去，就跳出提醒。
  4. 工程師手機的 Google 日曆會自動收到行程與提醒。

AI 設定

AI 判讀照片要用 Anthropic API 金鑰（費用由金鑰帳戶支付，一次查詢約新台幣 1～3 元）。金鑰只存在這台裝置的瀏覽器裡，不會放進網頁程式碼。照片若拍到病人姓名或病歷號，請先裁掉。

客戶與設備資料

目前是系統產生的虛構示範據點（示範醫院、示範診所…），位置只取各行政區大概位置。到職後把公司的設備清單（Excel 另存 CSV）貼到下面匯入，就會換成真實資料。資料只存在這台裝置。
